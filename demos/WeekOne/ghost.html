About Future ELIZA 2501

This is a second answer to the same prompt that produced the original Future ELIZA: ask Claude to build an ELIZA-style chatbot that would "respond like an AI from the future." The original was generated by Claude Sonnet 4 in 2025; this version was generated by Claude Fable 5 in 2026, after a request to lean slightly into the course's Ghost in the Shell framing and to give the bot more conversational range.

That range is still not intelligence. Like the 1966 original, everything here is pre-programmed pattern matching — no model is running behind this page. But this version borrows more of Weizenbaum's actual tricks: it reflects your own words back to you ("I am..." becomes "How long have you been...?"), it keeps a small memory of topics you have raised and circles back to them, and it varies its responses instead of repeating itself. Compare the two versions: the same prompt, one model generation apart. Does the extra machinery make the ghost feel any closer, or just the shell more elaborate?

Note: Expect nonsense. But notice which tricks make the nonsense momentarily convincing — that noticing is the exercise.
