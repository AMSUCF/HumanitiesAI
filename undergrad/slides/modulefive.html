Next week, Do: Describing the Archive

watch the video, then do the exercise and post by Thursday

Four steps

  • Build a set of 5-8 related images from the Library of Congress, Smithsonian, or Internet Archive
  • Save each item's catalog record
  • Ask an AI to describe and catalog each image, without the record
  • Compare, then ask it to sort the whole set
prompt.exe

step 2, one image at a time

> Describe this image in detail. Then write alt text for it (under 150 characters), and suggest a title, an approximate date, and five subject keywords as if you were cataloging it for a library.

Compare with the catalog

  • What did the AI get right?
  • What did it get wrong (dates, places, people)?
  • What did it assume or invent?
  • What does the catalog know that the image can't show?
